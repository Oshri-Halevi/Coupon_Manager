## על הפרויקט

האפליקציה מאפשרת למשתמש להתחבר עם חשבון Google ולנהל את כל הקופונים, כרטיסי המתנה וההנחות שלו: הוספה, עריכה, מחיקה, עדכון יתרה בזמן שימוש, וסינון/מיון לפי סטטוס, קטגוריה וחיפוש חופשי.

הנתונים מאוחסנים ב-Supabase (Postgres + Auth), כאשר כל משתמש רואה ומנהל רק את הקופונים ששייכים לו (באמצעות `user_id`).

## יכולות עיקריות

- **התחברות עם Google** (Supabase Auth / OAuth) — אין צורך בהרשמה עם סיסמה.
- **ניהול קופונים (CRUD)**: הוספה, עריכה ומחיקה של קופון/כרטיס מתנה/קרדיט.
- **סוגי הטבה**: הנחה באחוזים, הנחה בסכום קבוע, או כרטיס מתנה/קרדיט (עם תמיכה במטבעות ₪ / $ / €).
- **מעקב יתרה**: עדכון "יתרה נוכחית" בכל פעם שמשתמשים בקופון (מודל ייעודי `UpdateUsageModal`).
- **סטטוסים אוטומטיים** לכל קופון: פעיל / פג בקרוב (עד 7 ימים) / פג תוקף / נוצל — מחושב לפי תאריך תפוגה ויתרה.
- **סינון וחיפוש**: לפי חנות/קוד, קטגוריה וסטטוס.
- **מיון**: לפי תאריך תפוגה, ערך, שם חנות או תאריך הוספה (עולה/יורד).
- **תצוגות**: רשת (Grid) או רשימה (List).
- **לוח סטטיסטיקות (Stats)**: מס' קופונים פעילים, כמה פגים בקרוב, סה"כ יתרת קרדיט פעילה, וכמה נוצלו/פגו.
- **קטגוריות מובנות**: מזון ומשקאות, קניות, בידור, נסיעות ותחבורה, טכנולוגיה, יופי וטיפוח, ספורט ובריאות, מסעדות, חינוך, אחר.
- **SEO**: מטא-תגיות, `robots.txt`, `sitemap.xml` ואימות Google Search Console.

## מודל הנתונים

הטבלה המרכזית ב-Supabase היא `coupons`, עם השדות הבאים (כפי שנעשה בהם שימוש בקוד):

| שדה | תיאור |
|---|---|
| `id` | מזהה ייחודי |
| `user_id` | מזהה המשתמש הבעלים (Supabase Auth) |
| `store_name` | שם החנות/העסק (חובה) |
| `code` | קוד הקופון (אופציונלי) |
| `description` | תיאור קצר |
| `discount_type` | `percentage` / `fixed` / `gift_card` |
| `original_value` | ערך מקורי (או אחוז הנחה) |
| `remaining_value` | יתרה נוכחית |
| `currency` | `ILS` / `USD` / `EUR` |
| `category` | אחת מהקטגוריות המוגדרות |
| `expiry_date` | תאריך תפוגה (אופציונלי) |
| `notes` | הערות חופשיות |
| `created_at` / `updated_at` | חותמות זמן |

> יש להגדיר את הטבלה ב-Supabase (כולל Row Level Security כך שכל משתמש יראה רק שורות שבהן `user_id` תואם למשתמש המחובר), וכן לאפשר את ה-Google OAuth Provider בהגדרות ה-Auth של הפרויקט.

## התקנה והרצה מקומית

דרישות מוקדמות: Node.js וקובץ פרויקט Supabase פעיל.

```bash
npm install
npm run dev
```

האפליקציה תעלה בכתובת שמוצגת בטרמינל (בד"כ `http://localhost:5173`).

## משתני סביבה

יש ליצור קובץ `.env` בשורש הפרויקט עם המפתחות של פרויקט ה-Supabase שלך:

```
VITE_SUPABASE_URL=https://<project-ref>.supabase.co
VITE_SUPABASE_ANON_KEY=<anon-key>
```

> קובץ `.env` כבר קיים ב-`.gitignore` ולא אמור להיות מסונכרן ל-Git.

## Deployment

הפרויקט מוגדר לפריסה ל-Vercel (ראה `index.html` עם ה-URL הקנוני `https://coupon-manager-cyan.vercel.app`). יש לוודא שמשתני הסביבה (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) מוגדרים גם בהגדרות הפרויקט ב-Vercel.
